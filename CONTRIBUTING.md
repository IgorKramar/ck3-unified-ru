# Участие

Для ошибки укажите версию CK3, версии модов, порядок загрузки, сценарий, ожидаемое и фактическое поведение. Отделяйте проверенное наблюдение от предполагаемой причины. Удаляйте личные пути и данные из публикуемых отчётов.

Не добавляйте игровые файлы, извлечённые ресурсы, чужие переводы, приватные сборки или учётные данные. Для изменений утилит приложите небольшой синтетический пример и проверку. В описании PR укажите происхождение новых материалов и ограничения проверки.

Проверки: `python -m unittest discover -s tests -v`. Игровые кампании и Steam Deck проверяются отдельно; unit-тесты не заменяют их.
